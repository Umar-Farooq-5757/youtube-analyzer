# YouTube Analyzer

Analyze YouTube videos, channels and playlists.

## Layout:

### 1. Video
  * Title
  * Statistics
    * Views
    * Likes
    * Comments
    * Duration
    * Published on
  * Watch time at different speeds
  * Embedded video from YouTube
  * Thumbmail
  * Description
  * Tags
### 2. Channel
  * Picture
  * Title
  * Description
  * Statictics
    * Subscribers
    * Total views
    * Total videos
    * Created on
    * Total playlists
    * Country
  * Listed playlists
### 3. Playlist
  * Total Videos
  * Published on
  * List of all videos
    * For Each video:
      1. Thumbnail
      2. Title
      3. Views
      4. Likes
      5. Position in playlist
      6. Published on
      7. Duration
    * Sort playlist in ascending or descending order by:
      1. Views
      2. Likes
      3. Duration
      4. Title
      5. Published at
