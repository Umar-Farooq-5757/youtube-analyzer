# YouTube Analyzer

Analyze YouTube videos, channels and playlists.

## Layout:

### 1. Video
  * Title
  * Statistics
    * Views
    * Likes
    * Comments
    * Duration
    * Published on
  * Watch time at different speeds
  * Embedded video from YouTube
  * Thumbmail
  * Description
  * Tags
### 2. Channel
  * Picture
  * Title
  * Description
  * Statictics
    * Subscribers
    * Total views
    * Total videos
    * Created on
    * Country
    * Total playlists
